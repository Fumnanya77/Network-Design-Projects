# Network Design Projects
Efficient networking is the reason why the internet is what it is today.

Welcome to the **Network Design Projects** repository! This repo showcases a curated collection of practical and academic network design implementations. It includes topology diagrams, configuration files, and documentation for various scenarios — from small office LANs to enterprise-level campus networks, wireless deployments, and ISP topologies.

## 📁 Projects Included

| Project Folder                 | Description                                                                                                                                   |
|--------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| `Hotel System Network`         | A design implementation of a hotel system network design. The technologies implemented include: VLAN, SSH, OSPF, DHCP, and Switch Security.   |


---

## 🧰 Tools & Technologies

- **Simulators:** Cisco Packet Tracer
- **Protocols:** OSPF,VLAN
- **Services:** DHCP, SSH
- **Wireless:** WLAN, WLAN security [Port Security]
- **Design Standards:** Cisco hierarchical model, subnetting best practices
